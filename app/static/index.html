Options avancées

Chaque partie déborde sur la suivante (45 s en mode léger, 3 min en mode renforcé) : les voix entendues dans ce passage commun sont regroupées sous un même nom (« Voix 01 »…). Seules les personnes qui parlent dans ces passages sont reliées, les autres gardent des identifiants séparés. Utile seulement avec la distinction des intervenants.

Les cookies sont lus directement par yt-dlp uniquement si YouTube exige votre connexion. Fermez le navigateur concerné en cas d’erreur d’accès aux cookies.

Le téléchargement, le découpage et le stockage sont locaux. Les parties audio sont envoyées à l’API OpenAI pour la transcription, facturée sur votre compte. Le traitement continue si cet onglet est fermé, tant que la fenêtre de l’application reste ouverte.

Plage à transcrire (facultatif)

Intervenants

Les identifiants sont propres à chaque partie audio : une même personne apparaît sous plusieurs identifiants. Les voix les plus présentes sont en haut. Donnez le même nom à plusieurs identifiants pour les fusionner, puis enregistrez pour régénérer les fichiers.
